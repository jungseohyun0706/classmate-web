## 2. 학생 화면

### 2.1 홈(`/student/today`) 정보 계층
1. 상단: **학교 · 원래 소속 학년·반** (소속이 없으면 '소속 학급 미설정 — 담임 선생님 QR로 등록', 수업 그룹이 소속처럼 저장된 예전 학생도 '소속 학급 확인 필요'). 수업 칩을 눌러도 바뀌지 않음.
2. 내 수업 줄: 참여 중인 수업 제목 칩(최대 몇 개 + '전체'). 누르면 수업 정보(교사·기본 교실·요일·교시) 시트. 머리에 '+ 수업 담기'(`/student/courses#catalog`), 수업이 없으면 빈 안내 안의 '수업 담기' 버튼(R20).
3. **오늘의 내 시간표**(개인 시간표 카드): 날짜 이동(‹ ›), 상대 날짜 라벨(어제/오늘/내일/모레) + 실제 날짜·요일, 날짜 선택, 오늘로. 일간 목록. 전체 화면 `/student/timetable?date=`로 가는 링크. `/student/today?date=YYYYMMDD`(저녁 '내일 가방' 알림)로 열면 이 카드가 그 날짜로 열림.
4. **학급 시간표(참고)**: 개인 시간표 카드 밖, 바로 아래의 별도 접힘 영역(항상 '학급 시간표(참고) — 내 수업과 다를 수 있어요' 라벨, 개인 시간표 자리를 대신하지 않음). `/student/timetable`도 같은 규칙.
   - 볼 수 있는 학생: 승인된 소속 학급(학급 문서·학급 변경까지) / 담임 승인 대기(학년·반의 공개 NEIS만 — 승인 전 학급 문서는 읽지 않음) / `/api/timetable/me`가 서버·네트워크 오류로 실패해도 프로필의 승인된 소속 학급(서버 `homeroomOf`와 같은 규칙). 수업 그룹이 소속처럼 저장된 학생·거절된 학생은 없음.
   - 볼 수 있으면 머리줄은 항상 보이고(접어도 다시 펼칠 수 있음), 그 날 **공식 수업(수강·학급 공통 수업) 시간표가 없으면** 처음부터 펼침 — 직접 입력 일정은 세지 않음(일정을 추가해도 접히지 않음). 시간표를 못 받은 오류 때도 펼침. 학생이 접거나 펼치면 그 선택대로.
   - 교시 옆 시각(교시표), 오늘이면 수업 중인 교시에 '지금'.
5. 기존 기능 그대로: 급식(TodayCard에서 시간표 부분만 빼고 급식·일정), 가방 체크리스트, 급식 별점, 최신 알림장, 설치·알림 카드, 바로가기.

### 2.2 수업 카드
- 교시(·시각), 과목(·분반), **실제 수업 교실**, 담당 교사(있을 때).
- 변경: 빨간 테두리 + 배지 텍스트(시간 변경 / 날짜 변경 / 교실 변경 / 교사 변경 / 보강) + 전후('3교시 → 2교시', '3학년 4반 교실 → 영어전용실'). 사유·안내 시각은 펼쳐서.
- 직접 입력: 회색 점선 테두리 + '직접 입력 · 학교 시간표와 연결되지 않음'. 서버 반영 전이면 '저장 대기'.
- 취소·옮겨 간 수업은 실제 수업 목록과 분리된 안내 줄('영어 B 3교시 취소', '영어 B → 10월 8일(목) 3교시로 옮겨졌어요').
- 겹침: 노란 경고 줄('2교시에 수업 두 개가 겹쳐요').
- 내부 id·관리 필드는 보이지 않음.

### 2.3 날짜 탐색
- 이전/다음 날, 날짜 선택(input date), 오늘로. 주말·휴일도 선택 가능.
- 자료 기간(조회 창) 밖으로 가면 해당 기간을 다시 받아 옴.

## 4. 내 수업 화면(`/student/courses`)

- 참여 중인 수업(활성·승인 대기) 목록 — 출처(초대/명단/신청/공통 수업) 표시.
- **초대 코드 입력**(XXXX-XXXX) → `/i/{code}`.
- **수업 담기 (학교 수업 목록에서 고르기)**(R20, 시간표를 만드는 기본 방법): 학교가 공개한 수업을 시간표 칸(요일×교시)이나 과목으로 찾아 담은 수업에 모은 뒤 한 번에 담기(참여 방식에 따라 바로 또는 승인 대기). 겹침은 경고만. 내가 담은 수업은 '빼기'. 이름이 비슷하다는 이유로 자동 연결하지 않음.
- **직접 입력**(학원·자습 같은 학교 밖 일정): 제목, 매주(요일)/특정 날짜, 교시 또는 시각, 교실, 메모 — '학교 시간표와 연결되지 않음'. 같은 요일·교시에 학교 수업이 있으면 '이 시간 학교 수업'에서 담기·연결을 안내하고, 목록에는 '학교 수업과 시간이 겹쳐요' 안내.
- **공식 수업에 연결**: 직접 입력 일정을 참여 중인 공식 수업에 연결(학생이 직접 선택). 연결 전 차이·겹침을 보여 주고, 연결 후에는 공식 수업만 표시되고 메모는 보존.

## 5. 교사 화면

- `/dashboard`(메인): **오늘의 내 수업** — 선생님 본인 시간표(공식 수업 → 직접 등록 주간 시간표 → 빈 상태), 날짜 이동, 교환·보결 겹침, 아래에 급식·학사일정. 담임은 '우리 반 시간표 보기' 링크(학급 시간표는 메인 아님). 아키텍처 10절.
- `/teacher/courses`: 내 수업 목록, 수업 만들기, 담임 반 '학급 시간표 → 공통 수업으로 연결'.
- `/teacher/courses/[id]`: 기본 정보, 반복 차시(요일·교시·교실), 초대(학급·수업 구분 표시, QR·링크·코드, 만료·회수·사용 수), 수강생(승인 대기·추가·종료), 변경 이력, 검토 필요한 변경(orphan).
- `/teacher/schedule-changes`(알림 링크 `?changeSetId=`로 승인 요청 바로 열기): 대상 수업·날짜·차시 선택 → '이 날짜만' / '지정일부터 기본 시간표 변경' → 변경 전후 → 영향 학생 수·충돌(교사·교실·학생) → 사유 → 발행(동시 수정·재전송 안전). 다른 교사 수업이 섞이면 승인 요청.
- `/teacher/timetable-import`, `/teacher/roster-import`: 13·14장 흐름.
