요구 식별자 R01~R18, 검수 T01~T46은 지시서(`Classmate_Implementation_Master_Prompt_KO.txt`) 기준입니다. 구현·검증 대응은 `docs/classmate-timetable-qa.md`에 있습니다.

## 2. 학생 화면

### 2.1 홈(`/student/today`) 정보 계층
1. 상단: **학교 · 원래 소속 학년·반** (소속이 없으면 '소속 학급 미설정 — 담임 선생님 QR로 등록', 수업 그룹이 소속처럼 저장된 예전 학생도 '소속 학급 확인 필요'). 수업 칩을 눌러도 바뀌지 않음.
2. 내 수업 줄: 참여 중인 수업 제목 칩(최대 몇 개 + '전체'). 누르면 수업 정보(교사·기본 교실·요일·교시) 시트.
3. **오늘의 내 시간표**(개인 시간표 카드): 날짜 이동(‹ ›), 상대 날짜 라벨(어제/오늘/내일/모레) + 실제 날짜·요일, 날짜 선택, 오늘로. 일간 목록. 전체 화면 `/student/timetable?date=`로 가는 링크.
4. 기존 기능 그대로: 급식(TodayCard에서 시간표 부분만 빼고 급식·일정), 가방 체크리스트, 급식 별점, 최신 알림장, 설치·알림 카드, 바로가기.

### 2.2 수업 카드
- 교시(·시각), 과목(·분반), **실제 수업 교실**, 담당 교사(있을 때).
- 변경: 빨간 테두리 + 배지 텍스트(시간 변경 / 날짜 변경 / 교실 변경 / 교사 변경 / 보강) + 전후('3교시 → 2교시', '3학년 4반 교실 → 영어전용실'). 사유·안내 시각은 펼쳐서.
- 직접 입력: 회색 점선 테두리 + '직접 입력 · 학교 시간표와 연결되지 않음'. 서버 반영 전이면 '저장 대기'.
- 취소·옮겨 간 수업은 실제 수업 목록과 분리된 안내 줄('영어 B 3교시 취소', '영어 B → 10월 8일(목) 3교시로 옮겨졌어요').
- 겹침: 노란 경고 줄('2교시에 수업 두 개가 겹쳐요').
- 내부 id·관리 필드는 보이지 않음.

### 2.3 날짜 탐색
- 이전/다음 날, 날짜 선택(input date), 오늘로. 주말·휴일도 선택 가능.
- 자료 기간(조회 창) 밖으로 가면 해당 기간을 다시 받아 옴.

## 3. 상태 구분 (R15 / T34 / T35)

| 상태 | 판정 | 화면 문구 | 버튼 |
|---|---|---|---|
| 로그인 필요 | 인증 없음 | 로그인이 필요해요 | 로그인 |
| 가입 미완료 | users 문서 없음 | 가입이 아직 끝나지 않았어요 | 초대 코드 입력, 초대 링크 다시 열기 |
| 학교 미설정 | schoolCode 없음 | 학교 정보가 없어요 | 내 정보 확인 |
| 소속 학급 미설정 | classId 없음/그룹 | 소속 학급이 아직 없어요(수업은 따로 볼 수 있음) | 담임 초대 코드 입력 |
| 참여한 수업 없음 | 활성 수강·공통 수업·개인 일정 모두 없음 (`no-courses`) | 아직 연결된 수업이 없어요 | 초대 코드 입력, 공식 수업 찾기, 직접 입력, 학급 시간표(참고) 보기 |
| 승인 대기 | pending 수강 | ○○ 수업 승인을 기다리고 있어요 | — |
| 시간표 미등록 | 연결된 수업 모두 그 날 적용되는 기본 시간표 없음 (`not-registered`) | 수업은 연결됐지만 선생님이 아직 시간표를 등록하지 않았어요 | 학급 시간표(참고) |
| 일부만 연결 | 일부 수업만 미등록 (`coursesWithoutSchedule`) | 일부 수업 시간표가 아직 없어요 | — |
| 학기 밖 | 학기 기간 밖 (`outside-term`) | 이 날짜는 등록된 학기 밖이에요 | 오늘로 |
| 수업 없는 정상 날짜 | `no-lessons` | 이 날은 수업이 없어요 | — |
| 휴업일 | `holiday` | 오늘은 쉬는 날이에요(한글날) | — |
| 최초 로딩 | 요청 중 | 스켈레톤 | — |
| 오프라인·캐시 있음 | 네트워크 실패 + 캐시 | 마지막 동기화 HH:MM · 최근 변경이 반영되지 않았을 수 있어요 | 다시 시도 |
| 오프라인·캐시 없음 | 네트워크 실패 | 인터넷 연결을 확인해 주세요 | 다시 시도 |
| 권한 오류 | 403 | 이 시간표를 볼 권한이 없어요 | 내 정보 확인 |
| 서버 오류 | 5xx | 시간표를 불러오지 못했어요 (오류 코드) | 다시 시도 |
| 학사일정 확인 실패 | calendarErrors에 그 날짜 | 시간표는 보이되 '쉬는 날 여부를 확인하지 못했어요' 작은 안내 | — |

원인을 모르는 오류에 '수업이 없어요'를 표시하지 않습니다.

## 4. 내 수업 화면(`/student/courses`)

- 참여 중인 수업(활성·승인 대기) 목록 — 출처(초대/명단/신청/공통 수업) 표시.
- **초대 코드 입력**(XXXX-XXXX) → `/i/{code}`.
- **공식 수업 찾기**: 학교가 공개한 수업 목록(과목·분반·교사·요일 교시) → 신청(승인 정책에 따라 즉시 또는 대기). 이름이 비슷하다는 이유로 자동 연결하지 않음.
- **직접 입력**: 제목, 매주(요일)/특정 날짜, 교시 또는 시각, 교실, 메모 — '학교 시간표와 연결되지 않음'.
- **공식 수업에 연결**: 직접 입력 일정을 참여 중인 공식 수업에 연결(학생이 직접 선택). 연결 전 차이·겹침을 보여 주고, 연결 후에는 공식 수업만 표시되고 메모는 보존.

## 5. 교사 화면

- `/teacher/courses`: 내 수업 목록, 수업 만들기, 담임 반 '학급 시간표 → 공통 수업으로 연결'.
- `/teacher/courses/[id]`: 기본 정보, 반복 차시(요일·교시·교실), 초대(학급·수업 구분 표시, QR·링크·코드, 만료·회수·사용 수), 수강생(승인 대기·추가·종료), 변경 이력, 검토 필요한 변경(orphan).
- `/teacher/schedule-changes`(알림 링크 `?changeSetId=`로 승인 요청 바로 열기): 대상 수업·날짜·차시 선택 → '이 날짜만' / '지정일부터 기본 시간표 변경' → 변경 전후 → 영향 학생 수·충돌(교사·교실·학생) → 사유 → 발행(동시 수정·재전송 안전). 다른 교사 수업이 섞이면 승인 요청.
- `/teacher/timetable-import`, `/teacher/roster-import`: 13·14장 흐름.
